# Blackjack

Table de blackjack pour iPhone, installable sur l'écran d'accueil (Safari → Partager → « Sur l'écran d'accueil »).
Fonctionne hors ligne après la première ouverture.

Règles : sabot de 6 jeux, blackjack payé 3 pour 2, le croupier reste sur 17, doubler sur deux cartes, séparer jusqu'à 4 mains.
